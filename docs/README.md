# MOS 教程

从零用 Rust 在 x86_64 上写一个能跑在真机（UEFI 启动）上的自制操作系统。

## 章节目录

| 章节 | 内容 | 状态 |
|---|---|---|
| [00-启动流程](00-启动流程.md) | 从按下电源到内核运行：启动链条、为什么用 Limine、内核和普通程序的区别 | ✅ |
| 01-环境与工具链 | 每个开发工具的作用 | ✅（含在 00 章内） |
| [02-第一个内核](02-第一个内核.md) | 链接脚本、入口汇编、编译出第一个高地址内核 ELF + 两个新手必踩的坑 | ✅ |
| 03-串口输出 | IO 端口、让内核开口说话、日志系统 | 进行中 |

## 项目约定

- 开发在 QEMU 里迭代，阶段性在真机验证
- 内核语言：Rust（`no_std`）
- 引导器：Limine Boot Protocol
- 详细技术方案见仓库根目录的方案文档
